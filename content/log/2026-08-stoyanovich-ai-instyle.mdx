VIDA faculty member Julia Stoyanovich warned in a feature on AI's influence on beauty standards that AI image tools are accelerating aesthetic conformity the same way AI writing tools are flattening prose: "Diversity is changing because everybody's using ChatGPT to write, so everybody's text is similar. And this is a problem because the beauty, the originality is lost."
